TODAY’S CHALLENGE

One team. One property. One finished film.

Your team can divide the work, and the instructor assigns a team lead or director. The goal is to demonstrate image-to-video movement through the property. Extra beauty-shot B-roll is outside the challenge focus.

THE BRIEF

01 · SELECT REFERENCES

Start with the real place.

Download the exterior and interior images your team will actually use. Keep the same property as the visual anchor.

Bring in: the supplied property image website ↗ and a shared place for the team’s files.

Demonstration

  1. Select the views that can establish, enter or reveal the property.
  2. If a site delivers WebP and the next tool does not accept it, use a Chrome image-conversion extension to save PNG or JPEG.
  3. Open every saved file and agree which views the team will carry forward.
Useful result

The property is recognizable across the selected references and every file opens.

First failure

A file is unsupported, tiny or belongs to a different property.

First fix

Convert or replace that source image before generating anything from it.

02 · PREPARE VIEWS

Make the missing angles.

You can use the downloaded images directly. If the route needs another angle or a 16:9 frame, Nano Banana or GPT Image 2 can recreate the same property.

Why: a start frame and an end frame work only when they still look like the same place.

Demonstration

  1. Keep the building, structure and recognizable features fixed.
  2. Ask for a new angle or 16:9 composition only when the motion plan needs it.
  3. Review the approved stills together before animation. Reject a view that invents another building or changes the layout.
Demonstration boundary The rough-sketch conversion is a future-client use case shown in class. The instructor explicitly said the team challenge does not require a rough sketch.
Useful result

Each still can serve as a believable start or destination in the same property.

First failure

The architecture shifts before motion begins.

First fix

Return to the clearest reference and request one change at a time.

03 · BUILD MOTION

Move with a purpose.

Kling 3.0 Omni was demonstrated, but the instructor allowed another video model or approach. Use start-only when a clip does not need a prescribed destination; use start and end frames when the transition matters.

Why: movement should reveal the property while the walls, materials and layout stay stable.

Demonstration

  1. Choose the model and the start-only or start-plus-end-frame setup.
  2. Apply the supplied FPV structure only where it fits the selected property and view.
  3. Watch for warping, changing architecture, motion through solid walls and a destination that no longer matches.
  4. Simplify the move or repair the frames before spending more credits.
Useful result

The camera glides through open space and makes the property easier to understand.

First failure

Walls bend, rooms mutate or the camera passes through a solid surface.

First fix

Shorten or redirect the move and use a better-matched frame pair.

04 · CUT THE TEAM FILM

Cut the tour tight.

Bring the useful clips into Filmora, arrange one clear route and add music. The reference video includes beauty shots, but the challenge asks you to prioritize image-to-video movement.

Demonstration

  1. Choose the clips that establish, enter, connect or reveal the property.
  2. Cut them into one coherent walkthrough, then add music that supports the route.
  3. Remove filler and keep the full team film to about one minute or less.
  4. Watch the finished file and record the link and review notes in Homework.
Useful result

One team film, one readable property and no unnecessary detours.

First failure

The film becomes a collection of attractive but disconnected shots.

First fix

Keep the clips that clarify the route and remove the rest.
