Build one clear outcome.

Select an advanced VFX route, prepare compatible references, generate one video transformation test, and review what changed, what stayed stable, and the first correction.

MAKE ONE TEST

Prepare. Make. Review.

Choose a route that fits the footage and references available to you. Full source prompts live in the session guide prompt packet.

STEP 1

Choose one transformation and a base shot

Select one effect the available footage can support: object replacement, character and scene transformation, full scene redesign, motion transfer, character replacement, or reference-to-video. Identify the original clip and state what must change and what should remain stable before opening a generation tool.

Review: The chosen effect is specific, the base shot is identified, and the intended change is separated from details that should be preserved.

Goal: Name the intended change, base clip and details to preserve.

Inputs: Base video or frame, intended effect, and available footage.

Output: A one-sentence transformation plan.

First fix: If the change is vague, narrow it to one object, character or scene change before generation.

Next: Prepare only the references needed for that effect.

STEP 2

Prepare the reference set

Capture a useful frame when the source describes a screenshot workflow. Prepare only the references required by your route: subject, prop, costume, background, plain matte or other named elements. If using the reference-to-video route, the source demonstrates removing a subject from a frame, using the clip to ask Gemini for a prompt with explicit reference anchors, and attaching the prepared elements in Vidu Q2.

Review: Every reference has a clear role and agrees with the requested subject, scene, framing and motion.

Goal: Build references that agree on subject, scene and framing.

Inputs: Transformation plan, base clip, and needed subject, prop, costume, matte or scene images.

Output: A labeled reference set with a role for each asset.

First fix: If references conflict, resolve the identity, camera or background reference before choosing a model.

Next: Pick the video method that accepts these inputs.

STEP 3

Choose the video method for the transformation

Match the method to the job. The source pairs object replacement with Kling 1 Video-to-Video, a boxing scene with OpenArt video-to-video and Kling 3.0, scene replacement with Seedance 2.0, motion transfer with OpenArt Motion Sync and DreamActor M2.0 or Kling 3.0, character replacement with OpenArt Replace Body or Kling 01, and element-based reference-to-video with Vidu Q2. Treat the reported winners and issues as class observations rather than guarantees.

Review: The selected method supports the intended transformation and uses the references that method expects.

Goal: Match the tool and mode to the transformation and its references.

Inputs: Reference set and the use-case map in the session guide.

Output: A chosen tool/mode with a short reason.

First fix: If the route needs inputs you do not have, select another source-backed method or prepare the missing reference first.

Next: Use the corresponding complete source prompt as a starting point.

STEP 4

Generate one test and inspect the full clip

Use the closest complete source prompt or adapt a working copy for your own footage. Keep the transformation request focused and name the details the source says to preserve, such as face, body motion, timing, camera position, lighting, background or props. Review the clip from beginning to end instead of judging only its strongest frame.

Review: The test applies the requested change while retaining the selected identity, movement, timing and framing constraints.

Goal: Generate one test and inspect the whole video for drift.

Inputs: Chosen method, base clip, prompt and compatible references.

Output: A generated test link or saved clip.

First fix: If the result changes details that should stay stable, name the drift and simplify or clarify the relevant prompt/reference before another pass.

Next: Review identity, scene, movement, timing and lighting.

STEP 5

Record the result and the first correction

Compare the generated clip with the source. Note changes that worked, any identity or scene drift, lighting or relighting problems, unstable props, unwanted background changes, and motion that no longer matches. Save the selected clip and its source/reference links in the Homework Doc, then state the first correction supported by what you observed.

Review: A result link, selected method, source/reference links, review notes and evidence-based first correction are recorded.

Goal: Select a result and record what worked and the first correction.

Inputs: Source clip, generated test and the intended preservation rules.

Output: Homework record with tool, prompt, asset links, result, review and next fix.

First fix: If a note only says “it looks wrong,” identify the affected feature or moment and connect the correction to that evidence.

Next: Follow current cohort instructions for sharing or presenting the result.
