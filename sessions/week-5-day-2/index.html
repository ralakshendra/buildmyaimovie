02 · CHARACTER SHEET

Protect identity across views.

Assign face references and costume references separately. The Canva prompts distinguish which images control identity and which guide clothing.

Build a useful reference, not a single portrait.

  1. List the characters who appear in your assigned film.
  2. Gather approved face references and separate costume/armor references.
  3. Adapt the Canva prompt to the actual images; make each image placeholder’s role clear.
  4. Check turnaround views, expressions, costume details and proportions against the sources.
  5. Use the close-up prompt when a clean portrait is needed for the same person and costume.

Keep the sheet connected

Attach each prop to its relevant shot and character. A good-looking object that changes scale, design or owner between shots is not reliable continuity.

04 · GENERATION & REVIEW

Name the failure before the next pass.

Compare the result with its approved reference, then change the smallest useful part of the prompt or image guidance.

Make every iteration teach you something.

Formation shape

The instructor showed that models may turn the Chakravyuha into a generic spiral or maze. Start from the supplied formation reference, iterate toward its defining shape, and label any remaining mismatch as an approximation.

First fix: Reattach the shape reference and specify what must remain stable, including the gate and layered structure.

Character or prop scale

The Abhimanyu example exposed a wheel-size mismatch. Compare its size with the character and scene reference before approving the frame.

First fix: State the relative scale plainly and use a targeted regeneration when available.

Unexpected motion

The transcript notes bird-wing motion that missed the intended action and ground vibration interpreted as a blast.

First fix: Clarify and inspect the movement. The instructor demonstrated trimming and reversing a segment in the edit so blast-like movement reads as vibration.

Version choice

Decide with the team whether an imperfect but cinematic shot works for the story or whether the mismatch changes its meaning.

First fix: Compare versions with the source and record the compromise; do not present an approximation as exact.

Respect the subject.

The instructor encouraged experimentation and multiple viewpoints, and explicitly cautioned against spoof treatment of the Mahabharata project.
