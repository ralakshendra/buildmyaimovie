BEFORE YOU START

Bring your hero. Do not reboot them.

The superhero identity already exists. This Playbook turns it into a production-ready reference system, a cinematic teaser, and a published post.

EXECUTION SEQUENCE

Seven moves. One finished teaser.

Each task ends with one observable output. Finish that output before moving forward.

01
REFERENCE

Lock the hero for motion

Turn the existing superhero into a reference sheet that can survive video generation.

Do this

  1. Collect well-lit face references from several angles.
  2. Add one useful full-body or height reference.
  3. Open Google Flow or OpenArt image generation and use Nano Banana Pro, as demonstrated in class.
  4. Attach the references and use the official cohort character-sheet prompt.
  5. Customize the character and costume details that belong to your superhero.
  6. Use 4:3 or 16:9. In OpenArt, create 2 or 3 variations at 2K. In Flow, the class used 4 variations.
  7. Pick the strongest photoreal version and regenerate anything with face, eye, teeth, body, or costume drift.

Why it matters

The video workflow relies on Text with reference. This sheet is the continuity anchor for face, body, costume, and style.

Google Flow or OpenArt · Nano Banana Pro

Done when

  • Face still looks like you
  • Costume stays coherent
  • No major anatomy errors
  • Photorealism matches your intended style
Official prompt note

The full official character-sheet prompt was shared separately in the cohort workflow and is not fully present in the supplied transcript. Use that official prompt. This page does not invent a replacement.

02
WORLD

Build the superhero base

Give the model one place it can recognize from shot to shot.

Do this

  1. Choose one building, rooftop, bridge, clock tower, school, tech park, or another clear structure.
  2. Collect several real reference photos from useful angles.
  3. Use the architecture-sheet prompt supplied in class with the same general image-reference workflow.
  4. Generate a multi-angle architecture sheet.
  5. If background buildings steal focus, use closer references and make the intended structure the clear subject.

Why it matters

The hero can remain consistent while the environment mutates. The architecture sheet keeps the teaser inside one recognizable world.

Google Flow or OpenArt image workflow

Done when

  • Main structure is obvious
  • Several angles describe the same place
  • Background clutter does not dominate
  • The base is usable as a video reference
03
IDENTITY

Forge the title asset

Make the title feel like it belongs to the same superhero universe.

Do this

  1. Use your character sheet as the style reference.
  2. Open Flow or OpenArt and use Nano Banana Pro, as demonstrated.
  3. Use the official class title prompt and replace the title name with your own.
  4. Match useful hero cues such as emblem style, glow, material, and typography.
  5. If the glow is too strong, make a cleaner version on black.
  6. Remove the background with Adobe Express, Canva, OpenArt, Photoshop, or another clean method.
  7. Save the transparent PNG for editing.

Why it matters

The title is part of the reveal. A generic logo weakens the identity right when the teaser should feel most intentional.

Flow or OpenArt · background remover

Done when

  • Title is readable
  • Matches the hero identity
  • Letters are not damaged
  • Transparent PNG has clean edges
04
MOTION

Generate the hero moments

Build establishment, rescue, and action footage around the same references.

Do this

  1. Open OpenArt, choose Video, then Text with reference.
  2. Select Seedance 2.0 for the main A-roll workflow demonstrated in class.
  3. Add the architecture sheet and superhero character sheet as visual references.
  4. Make sure the correct image placeholders or reference tags point to the correct assets.
  5. Customize the class prompt so demo-specific character, building, and lighting details are replaced with yours.
  6. Generate establishment, saving-the-day, and fight or action moments.
  7. Run one important action prompt more than once and keep complementary results for the edit.

Why it matters

Two generations from the same action prompt can give you related movement that cuts together like a larger sequence.

OpenArt Video · Text with reference · Seedance 2.0

Done when

  • Hero identity survives motion
  • Base resembles the reference
  • You have useful action fragments
  • At least one alternate generation adds editing options
Official prompt note

The complete A-roll prompts were supplied separately in class and are not fully contained in the transcript. Keep the official prompt structure and update only the intended reference details.

05
SUPPORT

Generate only the B-roll you need

Add atmosphere, transitions, close detail, and breathing room for the edit.

Do this

  1. List the missing edit functions first: production title, rooftop walk, close-up, environment, transition, or atmosphere.
  2. For the production-house title example, the class used a text-to-video workflow without visual references, 16:9, 480p or 720p, roughly 6 to 8 seconds, with audio optional.
  3. For the rooftop walking reference shot, use OpenArt Text with reference and Kling 3.0 Omni, as corrected in class.
  4. Attach the character sheet and update the image anchor or reference tags correctly.
  5. Keep 16:9. A walking shot around 6 or 7 seconds was considered enough.
  6. Keep B-roll audio off when you do not need it. Keep generated SFX only when it helps.

Why it matters

B-roll gives you somewhere useful to cut when an A-roll generation breaks, and it lets you delay the full hero reveal.

OpenArt · Kling 3.0 Omni for rooftop walking example

Done when

  • Every support shot has an editing job
  • Hero and world remain connected
  • No random filler
  • You have clean cut points
AUDIO CHECK

Do not keep sound just because the model generated it.

If a close-up gives you a useful SFX, keep it. If the audio adds noise or fights the edit, switch it off and design the sound later.

06
EDIT

Cut it like a teaser

Turn generated fragments into one deliberate rise from mystery to reveal.

Do this

  1. Create a 16:9 Filmora project, as demonstrated in class.
  2. Import the useful A-roll, B-roll, and transparent title PNG.
  3. Open with atmosphere or establishment instead of the biggest hero reveal.
  4. Cut inside generated clips and keep only the convincing seconds.
  5. Combine useful action fragments from alternate generations.
  6. Build visual intensity with the music and sound rise.
  7. Choose a climax shot with negative space, then place the transparent title PNG on the upper layer.
  8. Optional: duplicate the shot and use a mask so scene elements can sit in front of the title.

Why it matters

A 15-second generation is raw footage, not a finished shot. Editing decides what the audience actually sees and feels.

Filmora workflow demonstrated in class

Done when

  • Reveal escalates clearly
  • Broken seconds are removed
  • Action cuts feel intentional
  • Title lands on a strong frame
  • Audio supports the same emotion
Publishing note: use music, dialogue, and sound effects you own, have permission to use, or can legally publish.
07
FINISH

Watch it. Fix it. Ship it.

Run focused review passes, export the final teaser, publish it, then submit the proof.

Do this

  1. Watch once for face, costume, and base continuity.
  2. Watch once for reveal pacing and weak cuts.
  3. Listen once for rhythm, abrupt audio, and competing sound.
  4. Check title readability and final placement.
  5. Confirm the project is 16:9 and export the version you want reviewed.
  6. Open the exported file once before posting.
  7. Publish the teaser.
  8. Open Homework and add the final links, proof, and reflection.

Why it matters

The class goal is a finished piece. Shipping closes the loop between generation, editing, publishing, and review.

Final export · publish · Homework submission

Done when

  • Hero remains recognizable
  • Base feels like one place
  • Title is clean
  • Pacing builds
  • Post and submission links work
