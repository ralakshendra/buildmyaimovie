PLAN BEFORE CREDITS

References first. Motion second.

If the face, costume, or building is unclear in the still references, video generation will only multiply the confusion.

STEP 1

Turn your existing superhero into a production character sheet.

The previous lesson gave you the hero identity. This step makes that identity usable for reference-driven video.

1. Gather clean face and body references

  1. Use your existing superhero identity as the creative direction.
  2. Collect multiple well-lit photos of yourself from different angles.
  3. Include one useful height or full-body reference when possible.
  4. Keep the photos consistent enough that the model is not solving a different face every time.

2. Build the sheet in Flow or OpenArt

  1. Open Google Flow or OpenArt image generation.
  2. Use Nano Banana Pro, as demonstrated in class.
  3. Attach the real-photo references as visual references.
  4. Use the official character-sheet prompt shared with the cohort. Customize the costume and character-specific parts before generating.

3. Use the demonstrated output settings

  1. Choose a horizontal aspect ratio: 4:3 or 16:9.
  2. 2K is enough for this reference-sheet stage.
  3. In OpenArt, create at least 2 or 3 variations.
  4. In Flow, the class suggested 4 variations because image generation there was being used freely in the demonstration.

4. Pick the sheet that deserves to reach video

  • Face still looks like you.
  • Eyes and teeth are not deformed.
  • Costume stays coherent across poses.
  • Body proportions do not jump between views.
  • Photorealism is intact instead of drifting into comic texture.
REFERENCE RULE

Bad source photos become expensive video problems.

Fix the still reference while it is cheap. The class repeatedly stopped students from moving forward with comic-looking or deformed character sheets.

Where is the full official character-sheet prompt?

The transcript confirms that the prompt was shared separately in the cohort workflow document and WhatsApp group. It is not fully present in the supplied transcript, so this guide does not invent it.

STEP 2

Build one superhero base the model can recognize.

Pick a real place or structure and turn it into a repeatable environmental reference.

1. Choose the location first

  1. Pick one place that can act as the hero's hub: a building, bridge, school, clock tower, tech park, rooftop, or another recognizable structure.
  2. Collect actual reference photos from as many useful angles as possible.
  3. Favor images where the intended structure is easy to identify.

2. Generate the architecture sheet

  1. Use the architecture-sheet prompt supplied in class. The instructor described this one as generic enough to work across different structures.
  2. Attach the location references in Flow or OpenArt using the same general reference workflow.
  3. Generate the sheet and inspect whether the same structure survives across views.

3. Remove environmental confusion

  1. If background buildings dominate, switch to closer references.
  2. Tell the prompt which structure deserves the focus.
  3. Do not use several unrelated buildings as equal anchors.

Ready for motion when

  • The main structure is obvious.
  • Its shape survives several angles.
  • Background structures do not steal focus.
  • The base looks like one place, not a collage of unrelated locations.
WORLD LOCK

Give the hero one address.

The more repeatable the location is in the architecture sheet, the easier it is to keep the teaser feeling like one movie.

STEP 3

Create the title as part of the superhero identity.

The class ties the title design back to the hero's emblem, glow, font feeling, and visual language.

1. Generate the title

  1. Open Google Flow or OpenArt.
  2. Use Nano Banana Pro, as demonstrated.
  3. Attach your character sheet as the reference.
  4. Use the official title prompt from class and replace the title name with your own.
  5. Describe the title so it follows the same emblem, glow, font feel, and material language as the hero.

2. Prepare the editing asset

  1. Keep the strongest title version.
  2. If glow is too heavy, generate a cleaner version or one on black.
  3. Remove the background with Adobe Express, OpenArt, Canva, Photoshop, or another tool you already use.
  4. Save the transparent PNG for the final edit.
Quick test: if the title could belong to any superhero, push it closer to your own costume and emblem language.
DIRECTOR’S NOTE

Choose the strongest hero moments.

Keep the character recognizable and select only the actions that move the teaser forward.

STEP 4

Generate the hero-facing A-roll.

The class uses A-roll as an easy organizing label for the main superhero moments, even though teaser editing does not technically use that classification.

1. Set up the reference-driven video

  1. Open OpenArt and choose Video.
  2. Switch to Text with reference.
  3. Select Seedance 2.0 for the A-roll workflow.
  4. Paste the official class prompt and remove instructor-specific references that do not belong to your project.
  5. Keep the square-bracket placeholders used by the class prompt, then retag them to your own hero and architecture references.

2. Attach the visual anchors

  1. Use Add visual references.
  2. Attach the superhero character sheet.
  3. Attach the architecture sheet where the shot needs the base.
  4. Confirm the references are successfully loaded before generating.

3. Build the main shot family

  • Hero establishment shots.
  • Hero saving-the-day moments.
  • Fight elevations or action beats.

The demonstrated A-roll examples were 15-second generations that were later cut down in editing.

4. Use variation on purpose

Generate the same action prompt more than once when useful. The class used separate generations of the same prompt, then combined their strongest action fragments into one larger sequence during editing.

Do not use Flow for this A-roll step: the class specifically corrected the workflow to OpenArt with Seedance 2.0.
STEP 5

Generate B-roll that solves editing problems.

Support shots should add atmosphere, transitions, detail, or a missing beat. They are not there to inflate the clip count.

Production-house title or text beat

  1. Use a text-to-video workflow without visual references when the shot does not need them.
  2. The class suggested Veo 3.1 or Kling 1.5 Pro for this text-heavy B-roll example.
  3. Use 16:9.
  4. 480p or 720p was considered enough for the generation stage.
  5. Use roughly 6 to 8 seconds.
  6. Keep audio off unless the shot actually benefits from generated audio.

Rooftop walking or close hero detail

  1. Return to OpenArt and use Text with reference.
  2. For the rooftop walking example, the class corrected the model to Kling 3.0 Omni.
  3. Attach the character sheet and update the image anchor tags.
  4. Keep 16:9.
  5. A walking shot around 6 or 7 seconds was considered enough.

Audio note: the class generally kept B-roll audio off, but a close-up can keep generated SFX if that sound is useful in the final cut.

STEP 6

Cut AI fragments into one teaser.

Generation gives you material. Editing creates the reveal.

1. Build the 16:9 project

  1. Open the editing project demonstrated in class and set it to 16:9.
  2. Import all useful A-roll, B-roll, and the transparent title PNG.
  3. Do not place every full generation back to back. Cut inside clips and keep only the convincing seconds.

2. Shape the reveal

  1. Start with atmosphere or establishment instead of immediately showing the biggest hero moment.
  2. Move between close detail, world shots, and hero action.
  3. Combine compatible action pieces from alternate generations to make one larger fight or save sequence.
  4. Let music and sound rise with the visual intensity.

3. Land the title at the climax

  1. Choose a shot where the hero sits on one side of the frame and leaves negative space.
  2. Place the transparent title PNG on the upper video layer.
  3. Scale it to fit the open space.
  4. Optional: duplicate the video layer and use a mask so the title can sit behind foreground elements for more depth.

4. Use audio you can actually publish

The class demonstrated adding dialogue, music, and sound effects for energy. For a publish-ready piece, use audio you own, have permission to use, or licensed/royalty-free alternatives.

EDITING RULE

Cut for the feeling, not for the generation.

A 15-second generation is raw footage. Keep the two good seconds if those two seconds make the teaser better.

SOUND PASS

Let sound sell the scale.

Music, dialogue, and effects should push the same emotion as the pictures. If the sound is fighting the cut, simplify it.

STEP 7

Review the cut, repair weak links, then publish.

Do four focused passes before export. Fix the source of a problem instead of blindly regenerating everything.

1. Watch only for continuity

  1. Ignore music and pacing for one pass.
  2. Check whether the face stays recognizable from shot to shot.
  3. Check costume details and the hero base for sudden changes.
  4. If something breaks, trace it back to the character sheet, architecture sheet, or missing reference tag.

2. Watch only for the reveal

  1. Start with atmosphere or establishment before the biggest hero moment.
  2. Trim weak seconds inside generated clips instead of keeping every 15-second output intact.
  3. Use alternate generations of the same action when they cut together better than one long take.
  4. Make sure the climax has enough breathing room for the title.

3. Run the title and sound pass

  1. Place the transparent title PNG over the planned negative space.
  2. If the title needs depth, use masking so parts of the scene can sit in front of it.
  3. Listen once without watching. Music and effects should still have a clear rise.
  4. Remove anything that fights the action instead of supporting it.

4. Export and publish

  1. Confirm the final project is 16:9.
  2. Export the version you actually want reviewed.
  3. Open the export once before posting and check the title, audio, and final frame.
  4. Publish the teaser, then use Homework for proof, links, and reflection.
TROUBLESHOOTING MAP

When something breaks, fix the earliest weak link.

Character turns comic-like

Regenerate or refine the character sheet before motion. The video model will inherit that texture.

Face or eyes drift

Return to stronger, well-lit face references and choose a better character-sheet variation.

Base becomes a random city

Use closer, cleaner structure references and make the intended building the dominant subject.

Title breaks during background removal

Generate a lower-glow or black-background version, then remove the background again.

A-roll looks inconsistent

Check that both character and architecture sheets are attached and correctly tagged in Text with reference.

One generation has only a few good seconds

That is normal. Cut the useful moment and combine it with another generation in the edit.

TROUBLESHOOTING

Change one thing at a time.

If you swap the model, prompt, references, and settings all at once, you will not know which change actually fixed the shot.
