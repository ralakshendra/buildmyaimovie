FIVE STAGES · ONE AD

Work in sequence

Keep the chosen character and product details consistent from frame to final edit. Detailed walkthroughs and original BMAMS practice prompts are in the session guide.

TASK 01 · Build the character

Build the character

Goal: Build one reusable creator identity.

Inputs: Your intended audience and character description; any reference images you are authorized to use.

Output: One named saved character selected for reuse.

Do: In OpenArt, use All Tools → Create Character. Build Your Character is the class's main from-scratch path: choose character traits, describe the look, turn on four variations, generate, select a result, Set as character, name it, and create it. The reference-image path starts from an image and supports up to four references in the session guide.

Record in homework: Record the character path, intended audience, any authorized reference-image links, the saved character name, and how you judged continuity.

Review: One named saved character is selected for reuse; its appearance fits the intended audience and any reference the team is authorized to use.

First fix: Compare the chosen face and appearance with your brief or authorized reference. Revise the mismatched trait before creating more variations.

Next: Use this saved character with the product reference in Task 2.

TASK 02 · Create the product-in-hand image

Create the product-in-hand image

Goal: Put the saved character and product into one usable frame.

Inputs: The saved character from Task 1, a clear authorized product image, and the exact approved label text.

Output: One selected 9:16 product-in-hand hero frame.

Do: In OpenArt image creation, select the saved character under visual references, attach a clear product image when available, and make a 9:16 hero frame. Use an available image model and current settings. Add accurate scene direction and approved product details to your prompt.

Record in homework: Link the product reference and selected hero image. Record the exact label text and what you checked for face, product, and lighting consistency.

Review: The selected frame shows the same saved character holding or using the intended product, with accurate packaging and legible product text.

First fix: Compare the image against the references. Identify the visible face, packaging, hand or label mismatch and change one relevant input before the next test.

Next: Use the selected hero frame as Task 3’s start frame.

RECORD IN OFFICIAL HOMEWORK DOC ↗

TASK 03 · Generate the talking A-roll

Generate the talking A-roll

Goal: Turn the hero frame into a clear talking message.

Inputs: The selected product-in-hand frame from Task 2 and approved dialogue with verified product claims.

Output: One selected talking A-roll clip with understandable audio.

Do: Use the product-in-hand frame as the start frame only, with no end frame, in an available start-frame video workflow. Turn audio on for dialogue. Use only verified, authorized product claims. If the line is cut off, shorten it or split it before spending credits on another generation.

Record in homework: Record the approved dialogue, the evidence or authorization for product claims, the start-frame choice, and your review of speech, face, hands, audio, and continuity.

Review: The spokesperson delivers the approved message with understandable audio, stable lip movement and hands, and continuity with the start frame.

First fix: If dialogue is clipped, shorten or split the line. If identity or hands drift, compare the clip with the start frame before another test.

Next: Keep this A-roll for the base layer of Task 5; prepare the product references for Task 4.

RECORD IN OFFICIAL HOMEWORK DOC ↗

TASK 04 · Create supporting B-roll

Create supporting B-roll

Goal: Add useful product coverage to support the message.

Inputs: The selected product-in-hand frame, product reference images, and the message established in Task 3.

Output: A selected product close-up and any useful product-use insert.

Do: Create a product close-up image using the product-in-hand frame as a visual reference. When a use-case insert adds useful information, generate a short B-roll clip using the relevant product images. Generation mode labels vary by account; choose an available mode and test with a short clip.

Record in homework: Link the close-up image and any product-use clip. Explain where each insert supports the message and note any mode or reference adjustment.

Review: Every insert adds a clear product detail or demonstrates use, with consistent lighting and accurate packaging.

First fix: Check the product and lighting against the reference. If a mode is unavailable, use an available supported route and test a short clip before making more inserts.

Next: Bring the useful inserts and talking A-roll into Task 5’s edit.

RECORD IN OFFICIAL HOMEWORK DOC ↗

TASK 05 · Edit, review, and export

Edit, review, and export

Goal: Assemble and review the final vertical advertisement.

Inputs: The selected talking A-roll, useful B-roll, and any audio you have permission to publish.

Output: One reviewed 9:16 advertisement export and its production evidence links.

Do: Use a suitable editor and a 9:16 project. Put lip-sync A-roll on the base layer and place useful B-roll over it. Keep transitions simple, add music only if it helps, use Foley when it supports the action, and export the vertical ad. Follow the cohort's current group instructions to share it.

Record in homework: Link the final vertical export. Record your review notes, first fix, what worked, what needed another pass, and where you shared it using the current cohort instructions.

Review: The exported vertical ad has clear dialogue, useful product coverage, truthful claims, consistent visuals, and no distracting effects.

First fix: If audio and picture disagree, inspect the relevant timeline section. Recheck the exported file from beginning to end after adjusting the edit.

Next: Record the final export and review notes in the official Homework Doc, then follow its current submission instructions.
