STAGE 01 · Build the character

Build the character

In OpenArt, use All Tools → Create Character. Build Your Character is the class's main from-scratch path: choose character traits, describe the look, turn on four variations, generate, select a result, Set as character, name it, and create it. The reference-image path starts from an image and supports up to four references in the session guide.

Look forOne named saved character is selected for reuse; its appearance fits the intended audience and any reference the team is authorized to use.

When it misses: inspect one variable at a time-reference, framing, claim, motion, or duration-then revise before another full run. Keep the selected output as the next stage’s input.

STAGE 02 · Create the product-in-hand image

Create the product-in-hand image

In OpenArt image creation, select the saved character under visual references, attach a clear product image when available, and make a 9:16 hero frame. Use an available image model and current settings. Add accurate scene direction and approved product details to your prompt.

Look forThe selected frame shows the same saved character holding or using the intended product, with accurate packaging and legible product text.

When it misses: inspect one variable at a time-reference, framing, claim, motion, or duration-then revise before another full run. Keep the selected output as the next stage’s input.

STAGE 03 · Generate the talking A-roll

Generate the talking A-roll

Use the product-in-hand frame as the start frame only, with no end frame, in an available start-frame video workflow. Turn audio on for dialogue. Use only verified, authorized product claims. If the line is cut off, shorten it or split it before spending credits on another generation.

Look forThe spokesperson delivers the approved message with understandable audio, stable lip movement and hands, and continuity with the start frame.

When it misses: inspect one variable at a time-reference, framing, claim, motion, or duration-then revise before another full run. Keep the selected output as the next stage’s input.

STAGE 04 · Create supporting B-roll

Create supporting B-roll

Create a product close-up image using the product-in-hand frame as a visual reference. When a use-case insert adds useful information, generate a short B-roll clip using the relevant product images. Generation mode labels vary by account; choose an available mode and test with a short clip.

Look forEvery insert adds a clear product detail or demonstrates use, with consistent lighting and accurate packaging.

When it misses: inspect one variable at a time-reference, framing, claim, motion, or duration-then revise before another full run. Keep the selected output as the next stage’s input.

STAGE 05 · Edit, review, and export

Edit, review, and export

Use a suitable editor and a 9:16 project. Put lip-sync A-roll on the base layer and place useful B-roll over it. Keep transitions simple, add music only if it helps, use Foley when it supports the action, and export the vertical ad. Follow the cohort's current group instructions to share it.

Look forThe exported vertical ad has clear dialogue, useful product coverage, truthful claims, consistent visuals, and no distracting effects.

When it misses: inspect one variable at a time-reference, framing, claim, motion, or duration-then revise before another full run. Keep the selected output as the next stage’s input.

FINAL REVIEW

Check the ad before export

  • One named character is saved and selected for reuse.
  • The 9:16 product-in-hand frame keeps character, packaging, and label details consistent.
  • The A-roll uses the approved dialogue, audio, and product image as its start frame only.
  • The spoken claims are verified and authorized; face, teeth, hands, and product contact look stable.
  • B-roll adds useful product detail and keeps the product and lighting consistent.
  • The 9:16 edit has clear dialogue, restrained transitions, useful audio, and a reviewed export.
Claims checkThe supplied demo uses fictional age and serum-use claims. Replace them with accurate, documented, authorized wording. Do not imply a real person’s endorsement or experience without permission.

Duration issue? Shorten the line or split it into clips as the class instructs. Avoid adding a transition to hide a continuity or dialogue problem.
