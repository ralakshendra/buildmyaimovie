TASK 1 · REFERENCE SET

Pick your property images.

Gather only the views your route needs.

What you need

  • The supplied property website ↗
  • A shared team folder
  • An image converter if a WebP file is unsupported

Do this

  1. Choose the exterior and interior images that can form a route.
  2. Save each reference. Convert WebP to PNG or JPEG only when needed.
  3. Open the saved files and agree which ones anchor the team’s film.

Save

Property reference links and the local files the team will carry into generation.

Review

The property is identifiable across the references and every file opens in the next tool.

Fix first

Replace or convert the failed source file before building new views from it.

Next dependency

Task 2 needs this approved reference set.

Practice recipe

Select the property images your team will use. If a file is WebP and the next tool will not accept it, convert it to PNG or JPEG and confirm the converted image opens before generation.

TASK 2 · APPROVED VIEWS

Build only the missing views.

Use the source images first. Make a new angle only when the route needs it.

What you need

  • Task 1 reference set
  • Nano Banana or GPT Image 2 if an additional view is needed
  • The team’s planned route

Do this

  1. Decide whether each shot can use a source image directly.
  2. If needed, request the same property at 16:9 or from another angle.
  3. Compare structure, windows, walls, materials and room relationships.
  4. Approve only the views that still read as one property.

Save

Approved still links and a short note describing what changed from the source.

Review

Each still is a useful start or destination and does not introduce a competing building or scene.

Fix first

Return to the clearest reference and request one change at a time.

Next dependency

Task 3 needs approved, matching views.

Practice recipe

When the walkthrough needs another view, ask Nano Banana or GPT Image 2 to keep the same property, building and structure while creating the needed angle or a 16:9 composition. Review the result for property continuity before animation.

TASK 3 · WALKTHROUGH MOTION

Make the camera move.

Give each shot a clear destination or a clear reason to move.

What you need

  • Task 2 approved stills
  • Kling 3.0 Omni or another image-to-video model the team understands
  • A purpose for every move

Do this

  1. Choose start-only or start-plus-end-frame for the shot.
  2. Use a supplied FPV prompt only when its structure fits the selected view.
  3. Generate and watch the entire move.
  4. Reject or revise warping, architectural drift, solid-wall crossings and unusable transitions.

Save

Model, mode, settings, clip links and which stills each clip uses.

Review

The camera move clarifies the property and the architecture remains recognizable.

Fix first

Simplify or redirect the move; repair the frame pair before another expensive run.

Next dependency

Task 4 needs only the approved, useful parts of these clips.

Practice recipe

Choose start-only or start-and-end image-to-video based on the shot. Test a purposeful camera move, then reject or revise any result that changes the architecture, passes through solid walls or breaks the visual continuity of the property.

TASK 4 · TEAM FILM

Cut the final film.

Build one clear route in Filmora, then add music.

What you need

  • Task 3 approved motion clips
  • Filmora
  • Music for the final edit

Do this

  1. Choose the clips that establish, enter, connect or reveal the property.
  2. Arrange one understandable route and add music.
  3. Remove beauty-shot filler and weak transitions.
  4. Keep the final film to about one minute or less, then watch the finished file.

Save

The final team video link and notes on what the team changed or removed.

Review

The edit is one coherent walkthrough with music and clear visual continuity.

Fix first

Remove the shot that breaks the route before adding more material.

Next dependency

The final review and cohort submission use this one team film.

Practice recipe

Arrange the approved motion clips into one real-estate walkthrough in Filmora, add music and trim away beauty-shot filler. Keep the final team film to about one minute or less.
