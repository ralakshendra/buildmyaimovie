01
NANO BANANA PRO / IMAGE WORKFLOW

Build your character and costume

Create the identity that every later shot will follow.

Bring in

  • An original hero name and personality
  • Several well-lit photos from different angles
  • Costume, emblem and color direction

Exact steps

  1. Choose the clearest face references and keep the raw files private.
  2. Generate a landscape character sheet with multiple useful views.
  3. Compare face, costume seams, emblem, materials and palette.
  4. Refine until the same person and same costume appear across the sheet.

Practice recipe

Subject: original hero identity
Reference: approved personal photos
Design anchors: costume silhouette, emblem, materials, color palette
Output: landscape character sheet with clear front and angle views

This is a practice recipe, not an official prompt.

Output

One approved landscape character sheet.

How you know

The face and costume read as the same design in every useful view.

If it fails

Use fewer, clearer references and simplify the design anchors before refining again.

Next: Give this hero a place that can survive a camera move.

02
IMAGE GENERATION

Design the hero's base

Build one recognizable location from several useful angles.

Bring in

  • One real building or place
  • Reference photos from multiple angles
  • The intended mood and time of day

Exact steps

  1. Select references that clearly describe the same place.
  2. Create a landscape environment sheet that keeps the architecture dominant.
  3. Compare materials, landmarks and scale across the views.
  4. Refine the composition if scenery hides the building.

Practice recipe

Place: one named architectural subject
Views: wide, angle and detail
Continuity: matching materials, lighting and landmarks
Priority: building remains the visual focus

This is a practice recipe, not an official prompt.

Output

One approved hero base sheet.

How you know

Every view feels like the same place and can guide a later shot.

If it fails

Remove background clutter and ask for a clearer architecture-first composition.

Next: Turn the hero identity into a title that can sit over footage.

03
IMAGE WORKFLOW + ADOBE EXPRESS

Make the title image

Create a bold hero title with a clean transparent background.

Bring in

  • The approved character sheet
  • The final hero name
  • A plain black background

Exact steps

  1. Generate the hero name or emblem using the character sheet as reference.
  2. Keep the first version on plain black for easy separation.
  3. Check spelling and readability at a small size.
  4. Remove the background in Adobe Express and export a transparent PNG.

Practice recipe

Text: exact hero name
Style link: shapes and materials from the approved costume
Background: plain black
Output: centered title artwork with clean edges

This is a practice recipe, not an official prompt.

Output

One transparent title PNG.

How you know

The title stays readable over both a bright and dark test frame.

If it fails

Simplify the lettering, fix the spelling and clean the edge before exporting again.

Next: Build the main moments that carry the teaser.

04
OPENART / GOOGLE FLOW

Generate the A-roll

Create the establishing, reveal and action beats.

Bring in

  • Approved character sheet
  • Approved hero base
  • One clear job for each shot

Exact steps

  1. Write one shot direction for an establishing view.
  2. Write one for the hero reveal and one for a simple action beat.
  3. Assign the correct character and location references.
  4. Generate with text plus references. Do not use start and end frames for this demonstrated method.
  5. Repeat the same direction for alternate takes when needed.

Shot recipe

Shot job: establish, reveal or action
Subject: approved hero
Location: approved base
Camera: one framing and one movement
Action: one readable beat
Continuity: preserve face, costume and architecture

This is a practice recipe, not an official prompt.

Output

At least one usable take for each main teaser beat.

How you know

The correct hero and place survive the full clip and the action reads immediately.

If it fails

Check the assigned references, simplify the action and regenerate the same shot job.

Next: Add just enough detail and sound to make the main beats hit.

05
SUPPORTING SHOTS + AUDIO

Add B-roll and sound

Strengthen the teaser without introducing a new visual world.

Bring in

  • Your approved A-roll
  • The transparent title PNG
  • Owned or licensed music options

Exact steps

  1. Watch the A-roll and identify one missing detail.
  2. Create a title animation, hero close-up or location detail that fills that job.
  3. Keep the same frame shape and reference system.
  4. Review generated sound effects and collect the useful ones.
  5. Choose a deliberate background score you can publish.

Supporting-shot recipe

Missing job: identity, scale, texture or transition
Reference: approved hero or base
Duration: only long enough to communicate the detail
Continuity: same costume, place and image shape

This is a practice recipe, not an official prompt.

Output

One or two useful supporting shots plus selected audio.

How you know

Each addition strengthens a main beat and still belongs to the same film.

If it fails

Remove the insert or rebuild it from the approved references.

Next: Turn the best pieces into a confident short sequence.

06
FILMORA

Edit the teaser

Build the reveal, layer the title and make the sound land.

Bring in

  • Approved A-roll and B-roll
  • Transparent title PNG
  • Sound effects and publishable music

Exact steps

  1. Create, name and save the Filmora project.
  2. Import every approved asset before editing.
  3. Arrange a clear opening, hero reveal, action beat and ending. Nonlinear order is fine when it reads clearly.
  4. Place the title above the footage and trim empty frames.
  5. Align sound effects to visible events and balance them with the score.
  6. Watch the complete timeline and remove black gaps or weak shots.

Edit rhythm

Open: orient the viewer
Reveal: make the hero readable
Escalate: use the strongest action beat
Brand: hold the title long enough to read
Exit: end on a deliberate image or sound

Output

One saved Filmora project with a complete teaser timeline.

How you know

No shot feels accidental, the title is legible and the audio supports the picture.

If it fails

Remove the weakest clip, tighten the reveal and resync sound around visible events.

Next: Export, watch the real file and share only the finished teaser.

07
FINAL QUALITY CHECK

Export, review and share

Finish the job by checking the actual file your audience will watch.

Bring in

  • The final saved timeline
  • Your Homework Doc
  • The cohort submission destination

Exact steps

  1. Export using the settings available in your workflow.
  2. Open the exported file outside the editor.
  3. Watch from first frame to last and check picture, title, sync and ending.
  4. Correct and re-export if anything is missing or broken.
  5. Add your proof and finished teaser link to the Homework Doc.
  6. Send the finished teaser to the cohort group before the session day ends.

Release scan

Identity: face and costume stay recognizable
World: location stays coherent
Title: readable with clean edges
Edit: no black gaps or accidental frames
Audio: synced and cleared for use
Privacy: raw face references remain private

Output

One fully reviewed teaser and one completed Homework Doc.

How you know

The exported file plays cleanly and the submitted item is the finished teaser.

If it fails

Fix the timeline, export again and repeat the complete review.

Finish: You made yourself the hero. Now give the teaser its premiere.
